Other searches go to the web as usual. Your password and 2FA are still needed after the word. Two or three unrelated words are best.

    Phone app

    Install cp as an app to share straight from other apps: pick Share → cp on a photo, file, link or text and the New share dialog opens with it. On Android open your browser menu and choose Install app or Add to Home screen (Chrome, Edge, Samsung Internet). iPhone and iPad can add cp to the Home screen, but Safari does not support the share sheet for web apps.

    API tokens

    A token lets a script or the cpup command create shares from a terminal. It can only create shares: it cannot list, open, change or delete them, or change settings. Tokens do not expire and stay valid after a password change: revoke one here when that machine no longer needs it.
